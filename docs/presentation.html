Idea Title & Proposed Solution Honeywell Technologies Campus Connect

SENTINEL — Explainable Behavioural Anomaly Detection

The Problem

  • 80% of breaches involve insider threats or compromised credentials
  • Analysts face 500+ daily alerts � can only review ~20
  • Rule-based systems generate noise; real threats get missed

Proposed Solution

  • Scores every access event in real-time (risk 0–100)
  • 5-detector ML ensemble working in parallel
  • Additive log-odds fusion → single interpretable risk score
  • Every alert: natural-language explanation + counterfactual
  • Live prototype deployed and accessible now
5 Detectors
Statistical Profile • IsolationForest • Markov Chains • Graph Anomaly • GRU Autoencoder

Research Basis

Leakage-free Feature Engineering

All features computed exclusively from past events — no train/test contamination in temporal data, ensuring valid out-of-sample evaluation.

Ensemble Anomaly Detection

Combines statistical, ML, and deep learning signals for robust coverage across heterogeneous attack patterns that no single model captures.

Explainability-by-Design

Log-odds decomposition gives exact per-feature contributions — not post-hoc SHAP approximations — enabling full audit trails for SOC analysts.
